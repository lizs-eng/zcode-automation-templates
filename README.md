# zcode-automation-templates

ZCode 自动化模板集：把 ZCode 从"问答工具"变成"无人值守员工"的实战配置与 prompt 模板。

全部内容来自一个**真实运行中的自动化系统**（每晚自动完成"选品→开发→自测→开源发布→生成报告"全流程，已连续运行多晚、踩坑全部记录）。不是文档翻译，是带血泪的实战模板。

## 免费样章（本仓库）

| 模板 | 用途 |
|---|---|
| `templates/01-定时任务最小模板.md` | 每晚自动干活的最小配置：创建步骤 + prompt 五要素骨架 + 已知坑 |
| `templates/02-网络诊断命令集.md` | CLI 工具连不上网时的 2 分钟诊断流程 + 故障对号入座表 |

## 完整版（¥39.9）

追加 5 个模板 + 3 份手册：

- **hooks 模板集**：提交前检查、自动格式化、危险命令拦截的配置写法
- **多阶段任务 prompt 模板**：探测→决策→执行→报告 的事件驱动结构（比清单式 prompt 成功率高一截）
- **AGENTS.md 规则文件模板**：怎么写规则让 agent 少犯错（含"验证不能把人工操作算成自动化成果"这类实录规则）
- **日志与验收模式**：每阶段小结 + 端点级验收，杜绝"看起来成功了"
- **无人值守安全红线清单**：哪些事永远留给人（实名/收款/对外发布…）
- **手册**：快速上手 / 定时任务与闲时任务 / 常见坑实录（覆盖事故、验收误判、工具循环等）
